# Lost And Alone
Survive the dark haunted forest where wild animals attack and your own psyche betrays you. Get to the rescue point to be saved.

## The Rescue Point
This location is along the border of the main world. A cityscape will be generated and upon entering the city you are rescued. A border of 20 is generated surrounding the main world.

## Terrain Generation
The terrain and biome is generated using perlin noise. Ponds occur below a z-level of -400 and mountains occur above a z-level of 2000. There are 3 tree types: Normal, Spruce and Dead which are determined by the biome noise. The spruce biome is the only biome which can generate mountains. Buildings, care packages, and rocks are all generated using randomness.

## Player

### Inventory
Care Packages give you random items that can help on your journey to the rescue point. Each care package can only be opened once. You can scroll through you inventory and use items by left-clicking. The item will be used and removed from your inventory.

### Vitals Component
You must manage your psyche, including: health, hunger, thirst, energy, comfort, and focus. All vitals must be kept high or else you risk death. There are items which you can eat, drink, fight and sleep with.

### Pond effects
If the player is below a z-level of -380, you will have a slowness effect and hear splashing.
